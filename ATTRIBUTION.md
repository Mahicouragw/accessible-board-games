# Attribution

HeroBoard contains **no copyrighted media**.

- **All sound effects** are synthesised at runtime by the **Web Audio API**
  (`js/audio.js`). They are original, generated tones and noise — no samples,
  no files, no licences.
- **Background music** is a gracefully generated ambient loop (also Web Audio).
- **All code** is written for this project under the MIT licence.
- **Icons / emoji** are the default system emoji on your device (platform
  glyphs), which are not redistributed as image assets.

## Third-party libraries (optional)
